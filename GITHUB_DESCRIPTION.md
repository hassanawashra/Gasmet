# Suggested GitHub details

## Repository name

`gasmet-static-chamber-flux-workflow`

## Short description

R workflow for processing Gasmet GT5000 static-chamber data with goFlux and analysing seasonal N2O fluxes from blocked field experiments.

## Suggested topics

`r` `gas-flux` `nitrous-oxide` `static-chambers` `gasmet` `goflux` `mixed-models` `agriculture`

## First release text

This repository provides a transparent R workflow for static-chamber gas-flux experiments measured with a Gasmet GT5000. It supports goFlux-based flux processing, individual-date figures, seasonal N2O plots with rainfall context, repeated-measures mixed models, soil-moisture analysis, and cumulative N2O-N calculations.

The repository contains code only. Raw instrument and field data are excluded to protect unpublished results and metadata. Users should follow the goFlux documentation for instrument import, observation-window selection, and package citation.
